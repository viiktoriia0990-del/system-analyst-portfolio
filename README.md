# Маркетплейс N · системная аналитика

Фрагменты аналитики по проекту маркетплейса N, где продают ювелирные изделия малые бренды и частные мастера. Данные обезличены.

| Модуль | Артефакт | Что внутри |
| --- | --- | --- |
| Оплата заказа | [Технический use case интеграции с ЮKassa](payment-use-case/README.md) | Основной и альтернативные сценарии, маппинг полей, статусы заказа, ошибки и таймауты, идемпотентность, вебхуки, примеры запросов и ответов, UML Sequence |
| Заявки продавцов | [API-контракт модуля](seller-verification/README.md) | OpenAPI 3.1: 8 методов (список с пагинацией, создание, чтение, изменение через PATCH, отправка, решение, архив и восстановление), бизнес-ошибки с примерами. AsyncAPI 2.6: событие в Kafka. Документация в ReDoc, mock-сервер Prism |

## Как смотреть

- Use case читается прямо на GitHub: таблицы и диаграмма Mermaid отрисуются автоматически.
- Модуль заявок продавцов запускается локально, инструкция в его [README](seller-verification/README.md#как-запустить).
